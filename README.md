# Linoor Next.js conversion

This project contains the Linoor theme as Next.js App Router pages while preserving its page structure, embedded images, icon fonts, and styling. The application reads its converted page markup from `content/` and its shared stylesheet from `public/theme.css`.

Run the site locally:

```bash
npm install
npm run dev
```

Available routes are `/`, `/about`, `/contact`, `/services`, `/shop`, and `/website-development`.
